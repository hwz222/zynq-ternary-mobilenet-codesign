# sw

Software that runs with the accelerator: the integer network in C, and the board apps.

## Contents

| path | what lives here |
|---|---|
| `net/` | `mbv2_pose.[ch]`: integer implementation of the whole network, layer by layer. It is the reference of every bit-exact gate, and it runs the head on the processor when `FUSE_HEAD_PL=0` |
| `app/pl_hal_fuse.[ch]` | register map and DMA arena of the accelerator, UIO lookup by name |
| `app/pl_hal_fuse_drv.c` | the same interface (`pl_hal_fuse.h`) on top of the kernel driver `linux/driver/twn_fuse`; built with `HAL=drv` |
| `app/pl_hal_fuse_enc.c` | the parts of the interface that touch no register (head descriptor encoders and checks, counter print), shared by both |
| `app/mbv2_fuse_ps.[ch]` | frame control, head in the PL or on the processor, post-processing (arg-max of the heatmaps) |
| `app/mbv2_ps.[ch]`, `app/pl_hal.h`, `app/pl_hal_zynq.c` | the processor-side network path (it provides `mbv2_ps_head()`, the head on the processor) and the hardware layer of an earlier per-layer accelerator; linked into every app |
| `app/mbv2_fuse_test.c` | the four fixtures, bit-exact check (`deploy.sh verify`) |
| `app/mbv2_fuse_pipe.c` | pipelined throughput measurement (`deploy.sh speed`) |
| `app/mbv2_fuse_eval.c` | a batch of pre-quantised images to raw outputs, for accuracy measured on the board (scored by `train/mbv2_pose/src/score_board.py`) |
| `app/main_cam.c` | `mbv2_cam_fuse`: USB camera (V4L2) in, keypoints drawn out; `--selftest golden/fix_N.bin` runs it on a fixture |
| `app/input_qlut.h` | int8 input quantiser table, generated by `tools/gen_input_qlut.py` |
| `app/Makefile.cross` | build of the four apps with the PetaLinux SDK |

## How to run

    bash board/build_apps.sh          # WSL, PetaLinux SDK; writes build/arm/
    bash board/deploy.sh data         # copies apps, weights and fixtures to the board

On the board, in `/home/root`: `FUSE_HEAD_PL=1|0` (head in the PL or on the processor),
`FUSE_BB2HD=1|0` (backbone-to-head direct write, default 1), `PIPE_TIMING=1` (per-stage times).

## Rules

- Build output goes to `build/arm/`, never into this tree.
- The register map in `pl_hal_fuse.[ch]` must match `rtl/fuse/twn_csr.v`; the arena offsets in
  `mbv2_fuse_ps.c` must match `tools/gen_fuse_ddr.py`. Change both sides together and re-run the
  frame test.
- Another task adds its post-processing as its own source file and its own target in
  `Makefile.cross`; it does not edit the pose post-processing.
- Generated headers (`tools/fuse_desctab.h`) are included from `../../tools/`; do not copy them here.
